# MR.4t — موقع البايو

موقع بايو فخم على طراز **guns.lol**، كامل في ملف واحد (`index.html`) + خلفية `bg.gif`.

## ✦ اللي فيه
- **شاشة بداية سينمائية**: شعار مونوغرام + شعار RGB دوّار + خطوط مسح، واضغط أي مكان للدخول (وهي الضغطة اللي تسمح بتشغيل الصوت).
- تخطيط **سكويّ** (عمود هوية + لوحة): على الجوال يصير عمود واحد.
- خلفية **GIF** متحركة (ملف `bg.gif`) مع تعتيم وتوهج وأورورا RGB وزوم بطيء.
- إطار RGB دوّار حول اللوحة + اسم بتدرّج قوس قزح + خط RGB + آفاتار بحلقة RGB.
- نجوم متطايرة + إضاءة تتبع الماوس + ساعة الرياض الحيّة.
- كرت **الدسكورد** الحي: الحالة (Online/Idle/…)، الاسم والتدرّج، تاق القيلد، الحالة المخصصة، سبوتيفاي/النشاط، وزر نسخ اليوزر.
- شاشة دخول `click to enter` — لأن المتصفحات تمنع تشغيل الصوت قبل ضغطة المستخدم.
- **موسيقى خلفية**: يشتغل ملف `music.mp3` تلقائيًا بعد الدخول، مع مشغل عائم + شريط إيكولايزر متحرك + شريط تقدّم.
- زر **تيك توك**: `@justmanbrev` + زر الأغنية.
- الحقوق: `© 2026 MR.4t — جميع الحقوق محفوظة` + `Designed & coded by MR.4t`.
- متوافق مع الجوال، ويدعم `prefers-reduced-motion`.

## ✦ الأغنية (مهم)
يوتيوب يمنع تشغيل كثير من المقاطع داخل المواقع (خطأ 150/153)، لذلك الأساس هو ملف صوتي محلي:

1. حط ملف الأغنية في نفس المجلد باسم **`music.mp3`** (أو `music.m4a` / `music.ogg` / `music.wav`).
2. خلاص — يشتغل تلقائيًا بعد ضغطة الدخول، ويكرر نفسه (Loop).

> إذا ما فيه ملف صوتي، يحاول الموقع تشغيل نفس الفيديو من يوتيوب كخطة بديلة.

## ✦ تشغيله محليًا
افتح `index.html` بالدبل كليك.

## ✦ نشره للجميع (مجاني)
1. **GitHub Pages** (الأسهل): أنشئ توكن من GitHub (Settings → Developer settings → Personal access tokens → Fine-grained token → صلاحية **Contents: Read and write** + **Pages: Read and write**)، وأعطني إياه وأنا أنشر الموقع وأرجع لك الرابط `https://<اسمك>.github.io/mr4t/`.
2. **Netlify Drop** — https://app.netlify.com/drop اسحب المجلد كامل → يعطيك رابط جاهز.
3. **Cloudflare Pages** — https://pages.cloudflare.com

> أي رابط تنشره يكون متاح للجميع فورًا.
